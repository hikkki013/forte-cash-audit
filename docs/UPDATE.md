# v0.3.0: обновление и запуск для жюри

Обновление содержит приложение, каталог правил, калибровки, интерфейс, тесты
и документацию. Python, библиотеки и модель не менялись. Это **не самостоятельное
приложение**: нужен распакованный Windows-пакет v0.2.0.

## Если проекта ещё нет

1. Откройте [базовый релиз v0.2.0](https://github.com/hikkki013/forte-cash-audit/releases/tag/v0.2.0).
2. Скачайте `Forte-Windows-v0.2.0.zip.part01`, `Forte-Windows-v0.2.0.zip.part02`
   и `Assemble-Forte.cmd` в одну папку. Дождитесь окончания обеих загрузок:
   файлов `.crdownload` быть не должно.
3. Запустите `Assemble-Forte.cmd`, дождитесь `CHECKSUM OK`, затем распакуйте
   полученный ZIP через «Извлечь всё». Выберите короткий путь, например `C:\Forte`.
4. Примените обновление ниже. Отдельно устанавливать Python, Git или модель не нужно.

## Если базовый пакет уже распакован

1. Остановите его сервер через **Ctrl+C**. Если нужны старые результаты,
   сохраните их до остановки: сервер хранит задания только в памяти.
2. Если меняли настройки, сохраните копию `config` **вне папки приложения**.
   Обновление заменяет профиль камеры и каталог; не переносите старый `scene.json`
   целиком поверх нового, иначе новые проверки могут оказаться выключены.
3. Откройте [релиз v0.3.0](https://github.com/hikkki013/forte-cash-audit/releases/tag/v0.3.0)
   и скачайте **`Forte-Update-v0.3.0.zip`**. Не выбирайте `Source code`.
4. Распакуйте ZIP. Откройте папку `Forte-Update-v0.3.0` и скопируйте **всё её
   содержимое** в корень старой сборки с заменой одноимённых файлов.
   Правильный корень содержит `Start-Forte.cmd`, `python` и `models` рядом.
   Папки `python`, `models`, `runtime` и пользовательские видео обновление не содержит.
5. Откройте `BUILD.json`: версия должна быть **0.3.0**, `runtime_base_version` — **0.2.0**.
6. Запустите `Check-Forte.cmd`. Ожидаются **`Enabled visual checks: 20`** и **`CHECK OK`**.
   Затем `Test-Forte.cmd`: все Python-тесты должны пройти. Тесты кода не доказывают
   точность распознавания на новых видео.
7. Запустите `Start-Forte.cmd`, оставьте окно открытым. В браузере откройте
   **http://127.0.0.1:8000/ui/with-rules/** и нажмите **Ctrl+F5**.
8. Загрузите свой MOV/MP4 до 200 МиБ и запустите анализ. Проверьте события,
   таймкоды, кадры и статусы всех 33 пунктов. Для 13 пунктов детектора пока нет.

Если по-прежнему видно 16 проверок, вероятно, обновление скопировано не в тот
каталог либо запущена другая копия сервера. Не отключайте защиту Windows и не
завершайте неизвестные процессы. [Проблемы запуска](TROUBLESHOOTING.md).

SHA-256 архива опубликован отдельным файлом `.sha256`. Встроенный PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Forte-Update-v0.3.0.zip
```

Сравните хеш с опубликованным. Отдельный архиватор не нужен. Для отката сохраните
базовый архив и распакуйте его в другую папку; не смешивайте старые и новые файлы.

## Разработчикам

Исходники находятся в ветке `master`, выпуск отмечен тегом `v0.3.0`. На чистой
копии выполните `git pull --ff-only`, проверьте отсутствие конфликтующих локальных
изменений и перезапустите сервер. Установка с нуля описана в [JURY_GUIDE.md](JURY_GUIDE.md).
Само обновление исходников не устанавливает Python или веса.

Релизное обновление собирается через `python -m scripts.build_update --base <v0.2.0>
--output <новый.zip> --commit <полный SHA>`. Сборщик проверяет неизменность требований,
установщика, загрузчика и весов модели относительно базового пакета; существующий
ZIP не перезаписывается. Файлы приложения и их хеши записываются в `BUILD.json`.
