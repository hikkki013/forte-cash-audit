# Windows-пакет для жюри

Готовый выпуск содержит встроенный CPython 3.12, зависимости Python, CUDA-библиотеки
PyTorch, декодер видео и локальные веса Grounding DINO Tiny. Он не устанавливает
Python в систему, не меняет PATH/реестр и не скачивает пакеты при запуске.
Git, Node.js, Docker, FFmpeg и CUDA Toolkit отдельно не нужны.

## Получение и запуск

1. Получите доступ к приватному репозиторию от владельца.
2. Откройте [Releases v0.2.0](https://github.com/hikkki013/forte-cash-audit/releases/tag/v0.2.0).
3. Скачайте `Forte-Windows-v0.2.0.zip`. **Source code (zip)** не содержит встроенного окружения и не заменяет этот пакет.
4. Распакуйте архив полностью в доступную для записи папку, например `C:\Forte`.
5. Запустите `Check-Forte.cmd`, дождитесь `CHECK OK`, затем `Start-Forte.cmd`.
6. Браузер откроет `http://127.0.0.1:8000/`. Загрузите своё MOV/MP4 до 200 МиБ.
7. Для проверки кода запустите `Test-Forte.cmd`; это не измерение точности модели.
8. Не закрывайте окно сервера во время анализа. Завершение — Ctrl+C.

После распаковки интернет для анализа не нужен. Видео не отправляются на облачный
сервер. Служебная копия загруженного видео удаляется после завершения задания;
исходный файл не меняется. Результаты сервера находятся в памяти и исчезают после
остановки. Диагностические отчёты, если запускались вручную, остаются локально.

## Ограничения среды

- Только Windows 10/11 x64; macOS/Linux/ARM этой сборкой не поддерживаются.
- Рекомендуются 16 ГБ RAM и 15 ГБ свободного места на этапе распаковки.
- Для проверенной скорости нужен NVIDIA GPU и совместимый драйвер для CUDA 12.8.
  На разработке использована RTX 4050 Laptop 6 ГБ. 4 ГБ и другие модели не проверены.
  Драйвер устанавливает владелец компьютера; он не входит в приложение.
- Без CUDA используется CPU, возможен таймаут. Предел пяти минут для всех видео
  и компьютеров не гарантируется.
- Нужен свободный порт 8000. Если он занят, остановите предыдущую копию Forte;
  приложение не завершает чужие процессы. При необходимости команда
  `python\python.exe -I scripts\portable.py --port 8010` запускает другой локальный порт.
- Антивирус/политика организации могут запрещать запуск неподписанных CMD/EXE.
  Не отключайте защиту; согласуйте запуск с администратором. Цифровая подпись
  издателя для пакета не выпускалась.
- Проверка переносимости выполнена в отдельной папке со своим Python и очищенным
  PATH на компьютере разработки. Это **не проверка на чистой Windows/другом GPU**.

## Состав и воспроизводимость

Проверка выпуска на компьютере разработки: 125 Python-тестов, оба набора JS-тестов,
офлайн-загрузка модели и CUDA-операция прошли. Через HTTP переносимого сервера
видео 22 дало `key_left_in_lock` на 00:15 с тремя кадрами; видео 23 — без событий.
Файлы отправлялись под нейтральным именем. Это проверка интеграции на знакомой
калибровочной паре, не независимая оценка качества и не проверка чистой Windows.

- `BUILD.json`: версия и SHA-256 файлов приложения/весов.
- `DEPENDENCIES.json`: точные версии установленного окружения этой сборки.
- `python/`: переносимое окружение, стандартная библиотека, DLL и зависимости.
- `models/grounding-dino-tiny/`: веса, конфигурация, tokenizer и сведения о происхождении.
- `config/`: зоны, экспериментальные калибровки и каталог 33 проверок.
- `tests/`: локальные Python-тесты. Node-тесты интерфейса выполняются при подготовке выпуска, Node не включён в пакет.
- `THIRD_PARTY_NOTICES.md`, `python/LICENSE.txt`, лицензии внутри `*.dist-info` и `licenses/`: сведения о сторонних компонентах.

В пакет не входят исходные видео, закрытые таблицы, PDF, пользовательские отчёты,
ключи API, токены, история Git и кэш скачивания модели. При первом запуске создаётся
свой локальный `runtime/api-key.txt`; не отправляйте его в репозиторий.

## Для сборщика, не для жюри

Используйте подготовленную `.venv` и лицензированный x64-каталог MSVC CRT.
Скрипт сборки не скачивает зависимости и не перезаписывает существующую сборку:

```powershell
python -m scripts.build_portable --destination dist/Forte-Windows-v0.2.0 --crt "C:\path\x64\Microsoft.VC145.CRT" --ms-licenses "C:\path\Licenses\1049"
```

Проверьте `Check-Forte.cmd`, тесты и загрузку своих положительных/отрицательных
видео через локальный сервер. После финальных правок исходников:

```powershell
python -m scripts.build_portable --destination dist/Forte-Windows-v0.2.0 --refresh-source
python -m scripts.build_portable --destination dist/Forte-Windows-v0.2.0 --archive-only
```

Архиватор исключает служебные данные, появившиеся при проверке. Рядом записывается
SHA-256 архива. Перед публикацией проверить состав ZIP, соответствие `BUILD.json`
коммиту и применимые лицензии компонентов. Не включайте папку `dist` в Git.
