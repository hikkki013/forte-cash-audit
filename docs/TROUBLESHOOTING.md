# Если что-то не запускается

[← README](../README.md)

| Симптом | Что проверить |
| --- | --- |
| GitHub показывает 404 | Репозиторий приватный. Войти в приглашённый аккаунт и принять приглашение владельца. |
| `py` или Python 3.12 не найден | Установить Python 3.12 либо передать существующий полный путь в `setup.ps1 -Python`. Python 3.14 не является проверенной средой этого проекта. |
| PowerShell запрещает скрипт | Использовать приведённую команду `powershell -ExecutionPolicy Bypass -File ...`; это разовый процесс, не глобальное изменение политики. |
| Скачивание долго не заканчивается | CUDA-пакет занимает несколько гигабайт. Проверить сеть/место, затем повторить установку. Не отключать проверку TLS. |
| `Local model missing` | Из корня проекта выполнить `.\.venv\Scripts\python.exe -m scripts.download_model` с интернетом. Если в этом окне включён HF_HUB_OFFLINE, использовать новое окно. |
| CUDA=False | Проверить NVIDIA-драйвер и `.venv`, вызвать `nvidia-smi`. `setup.ps1` устанавливает сборку CUDA 12.8; CPU-время не сравнивать с GPU-замерами. |
| Недостаточно видеопамяти | Закрыть собственные параллельные GPU-задачи и повторить. На 4 ГБ работоспособность не подтверждена. Не запускать несколько работников uvicorn. |
| Порт 8000 занят | Проверить `http://127.0.0.1:8000/health`: возможно, API уже работает. Не завершать чужой процесс; остановить свой сервер через Ctrl+C. |
| HTTP 401 | Нужен ключ текущего сервера в заголовке `X-API-Key`. `change-me` из макета не подходит. |
| HTTP 503: ключ не настроен | Запускать через `scripts/start.ps1` либо задать FORTE_API_KEY перед стартом uvicorn. |
| HTTP 413 / 415 | API принимает MOV/MP4 до 200 МиБ; макет фронта имеет более узкий лимит. |
| HTTP 429 | Очередь заполнена. Дождаться предыдущих заданий. |
| HTTP 404 для job_id | Неверный ID, истёк срок хранения либо сервер перезапущен. |
| `analysis_timeout` | Бюджет исчерпан, включая очередь/холодный старт. Проверить длину видео и GPU; это не результат «нет нарушений». |
| `analysis_failed` | Проверить воспроизводимость через CLI: там виден traceback. Не публиковать логи с ключами/чувствительными путями. |
| Unsupported camera aspect | Пропорции не совпали с профилем. Нужна отдельная настройка сцены, не просто изменение порога для обхода проверки. |
| No people detected | Сцена не может быть оценена. Пустой/неподходящий ракурс нельзя автоматически объявить нормальным. |
| Кнопка в красивом фронтенде не анализирует | Интеграция не выполнена. Использовать `/docs` либо CLI. Не запускать `frontend/*/main.py` как настоящую модель. |
| Видео не воспроизводится в браузере | Поддержка MOV зависит от браузера/кодека. Это не доказывает, что PyAV не может обработать файл; проверить CLI. |

Все команды запускаются из корня клона. Модель и конфигурация по умолчанию ищутся относительно текущей рабочей папки.
