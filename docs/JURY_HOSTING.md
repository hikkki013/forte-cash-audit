# Публичный API для жюри на компьютере команды

Этот режим нужен только если жюри должно отправлять видео с другого компьютера.
Обычный `Start-Forte.cmd` остаётся локальным и безопаснее для демонстрации.

## Адрес

Для текущего внешнего IPv4 команды выбран временный DNS-адрес:

`https://95-82-64-242.sslip.io`

`sslip.io` только возвращает DNS-запись на этот IP; видеотрафик идёт напрямую на
компьютер команды. Если внешний IP изменится, замените содержимое
`runtime/jury-domain.txt` на новый адрес вида `A-B-C-D.sslip.io` и перезапустите
сервер. Для стабильного адреса на весь конкурс лучше настроить собственный домен
или DDNS у роутера.

## Публикация

1. В панели роутера перенаправьте **TCP 80** и **TCP 443** на этот компьютер.
   Номер локального адреса проверьте в `ipconfig`; на момент подготовки это
   `172.20.10.4`. Закрепите его в настройках DHCP роутера, иначе правило может
   сломаться после переподключения.
2. Один раз запустите `Enable-Jury-Firewall.cmd` **от имени администратора**.
   Он открывает входящие TCP 80 и 443 только для `caddy.exe`. Не открывайте
   порт 8000: Forte остаётся доступен только локальному Caddy.
3. Установите Caddy: `powershell -ExecutionPolicy Bypass -File .\scripts\install-caddy.ps1`.
4. Создайте `runtime\jury-domain.txt` с единственной строкой
   `95-82-64-242.sslip.io`.
5. Запустите `Start-Jury-Server.cmd`. Caddy получит и будет обновлять HTTPS-
   сертификат автоматически. Порты 80 и 443 должны быть доступны извне, иначе
   сертификат не будет выдан.
6. Передайте жюри URL и значение из `runtime\api-key.txt` отдельным закрытым
   сообщением. Не добавляйте этот файл в Git, чат с посторонними или скриншоты.

## Режим и следы обработки

В `Start-Jury-Server.cmd` включён `FORTE_API_KEY_ONLY=1`: вызовы
`/api/v1/analyze` и `/api/v1/jobs/{job_id}` без `X-API-Key` получают 401, даже
если ранее был открыт локальный интерфейс. В `runtime/jury-audit.jsonl` пишутся
только UTC-время, `job_id`, событие `accepted`/`finished`, статус, длительность
и безопасный код ошибки. Имя, IP-адрес, содержимое и кадры видео в этот журнал
не попадают.

Служебная копия загруженного видео удаляется после задания. Результат с
Base64-кадрами находится только в памяти процесса и пропадает после перезапуска.
Перед запуском подтвердите у организаторов, что прямой доступ к вашему компьютеру
и временная обработка тестовых видео на нём допустимы.

## Проверка с другой сети

Проверяйте не из домашней Wi-Fi сети: используйте мобильный интернет другого
устройства. До передачи адреса жюри убедитесь, что `https://95-82-64-242.sslip.io/health`
открывается, а запрос без `X-API-Key` к `/api/v1/analyze` получает 401.
