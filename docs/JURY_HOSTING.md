# Публичный API для жюри на компьютере команды

Этот режим нужен, когда жюри должно отправлять видео со своего компьютера, а не
на ноутбуке команды. Он не требует доступа к роутеру, статического IP или
открытия портов. Обычный `Start-Forte.cmd` остаётся локальным.

## Быстрый способ: временный Cloudflare Tunnel

Туннель создаёт исходящее зашифрованное соединение с Cloudflare. Публичный адрес
вида `https://...trycloudflare.com` выдаётся при каждом запуске, работает только
пока открыто окно скрипта и не рассчитан на постоянный production-хостинг.
Видеотрафик при этом проходит через Cloudflare; используйте этот способ только
если организаторы разрешили такой транзит тестовых видео.

Для соединения самого `cloudflared` сеть должна разрешать исходящий UDP **или**
TCP-порт `7844` к Cloudflare. На текущем университетском Wi-Fi оба направления
заблокированы: подключите ноутбук к личной мобильной точке доступа либо попросите
администратора сети разрешить исходящий порт 7844. Открывать входящие порты на
роутере не требуется.

1. Откройте PowerShell в корне проекта и один раз выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\install-cloudflared.ps1
   ```

2. Запустите `Start-Jury-Tunnel.cmd` двойным щелчком. Окно нельзя закрывать до
   окончания проверки.
3. Дождитесь строки с адресом `https://...trycloudflare.com`. Он также появится
   в `runtime\jury-tunnel-url.txt`. Для интерактивной проверки откройте
   `<этот-адрес>/docs`.
4. Передайте жюри адрес и содержимое `runtime\api-key.txt` отдельным закрытым
   сообщением. Не добавляйте ключ, URL или видео в GitHub, общий чат или
   скриншоты.
5. Жюри отправляет `POST /api/v1/analyze` с MOV в поле `file` и заголовком
   `X-API-Key`, затем опрашивает `GET /api/v1/jobs/{job_id}` до `done` или
   `failed`.

Порт 8000 остаётся привязанным к `127.0.0.1`: снаружи он не открыт. Запрос без
верного `X-API-Key` к `analyze` или `jobs` получает HTTP 401. `runtime\jury-audit.jsonl`
содержит только UTC-время, `job_id`, событие, статус, длительность и безопасный
код ошибки — без имени, IP-адреса, видео и кадров. Временная загрузка удаляется
после задания; результат с Base64-кадрами живёт только в памяти процесса.

## Проверка перед передачей

Откройте `<этот-адрес>/health` через мобильный интернет другого устройства.
В Swagger на `<этот-адрес>/docs` запрос без ключа к `POST /api/v1/analyze`
должен вернуть 401. Не загружайте тестовые ролики жюри сами: они предназначены
для их закрытой проверки.

## Альтернатива: собственный домен и Caddy

`Start-Jury-Server.cmd` сохраняется для сети, где можно перенаправить TCP 80 и
443 на этот компьютер и есть стабильный домен. На текущей сети это не подходит:
шлюз недоступен и адрес локальной сети не является публичным. Этот вариант не
нужен для Cloudflare Tunnel; открывать порт 8000 нельзя ни в одном из вариантов.
