# Два варианта интерфейса — правки текстов

Исходный пользовательский архив сохранён без изменений в Downloads.

- `forte_с_правилами` — со справочником возможностей и ограничений.
- `forte_без_правил` — без справочника.
- CSS и изображения сохранены побайтно. Кнопки, DOM-раскладка, классы, размеры, отступы и адаптивные правила не изменялись. Новый текст может переноситься иначе.
- Вместо обещания отсутствия нарушений показывается отсутствие событий по включённому правилу.
- Справочник описывает один включённый сценарий; остальные обозначены как выключенные или не реализованные. Непроверенные пересказы закона заменены описанием возможностей программы.
- Исходное ограничение фронта сохранено: MOV до 50 МиБ. Backend допускает также MP4 и размер до 200 МиБ; более узкий лимит фронта допустим.

Небольшие исправления без изменения оформления: относительные пути логотипа/иконки, отсутствие обращения к несуществующему справочнику во втором варианте, чтение вложенного `job.result` с проверкой формата, русские названия событий вместо технических ID.

## Интеграция ещё не выполнена

`main.py` из архива — демонстрационная заглушка, а не наш анализатор. Она всегда возвращает отсутствие нарушений; **не использовать её для проверки видео**. Также она ожидает отсутствующую папку `static`. Файл оставлен без изменений как часть исходного примера, не запускался.

Рабочий анализатор — `forte.api` в корне проекта. Контракт: `docs/API.md`. В `app.js` остался исходный ключ-заглушка `change-me`; настоящий ключ в интерфейс не добавлялся. Для подключения нужны раздача фронта рядом с API и согласованная авторизация либо отдельные API base URL/CORS. Эта итерация меняет тексты, не выполняет подключение.

## Просмотр

Из корня проекта выполнить:

```powershell
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

Открыть http://127.0.0.1:8765 и выбрать папку варианта. Это просмотр, не анализ видео. Остановка: Ctrl+C.
