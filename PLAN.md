# Ближайший план без усложнений

1. Рабочий контур: локальная модель → правило → кадры → FastAPI. Реализован; демонстрируем только проверяемый сценарий с банкнотами и уходом к выходу.
2. Интерфейс участника подключён: загрузка, ожидание, список событий, таймкод, кадры, предупреждения. Запуск через Start-Forte.cmd, единый адрес http://127.0.0.1:8000/. Исходное оформление сохранено.
3. Проверить этот сценарий на отдельных видео, которые не использовали для настройки. Хранить ошибки и пропуски; не считать соседние кадры независимыми тестовыми примерами.
4. Добавлять по одному сценарию. Сначала подтвердить видимые признаки и разметку, потом включать правило. Сейф/ПК потребуют отдельной проверки состояний; «экран чёрный» не доказывает выключение компьютера.
5. Сопоставление с нормативными пунктами утвердить отдельно по актуальному тексту и правилам конкурса. Не выдавать эвристику за юридически установленный факт.

Для следующего шага нужны независимые видео с ожидаемыми результатами для проверки покрытия. Не требуется обучать большую модель с нуля.

Не включаем сейчас: распознавание лиц, большие мультимодальные облачные сервисы, обучение end-to-end на 24 роликах, универсальную поддержку любых камер. Прототип не удовлетворяет обещанию распознавать неизвестные типы нарушений автоматически.
