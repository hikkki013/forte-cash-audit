# Архив исследовательского baseline

`Forte_01_baseline.ipynb` — ранний эксперимент с признаками ResNet18 и небольшим классификатором. Это **не текущий Grounding DINO pipeline** и не обязательный этап установки для жюри.

Notebook сохранён без outputs/attachments. Он может требовать отдельной подготовки входных данных и облачного окружения. Не загружайте материалы кейса в стороннее облако без разрешения владельца данных и правил конкурса.

Для текущей локальной версии используйте инструкции корневого README и `docs/JURY_GUIDE.md`.
